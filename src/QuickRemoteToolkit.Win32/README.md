# Win32-прототип

Отдельное приложение на C++17 и Windows API без .NET. Это прототип для сравнения
интерфейсов, а не полная замена WPF-версии. Исходники WPF остаются в проекте.

Работают загрузка CSV в UTF-8 и Windows-1251, поиск, таблица, копирование полей
через контекстное меню, сворачиваемые блоки и экспорт журнала в UTF-8 TXT.
Есть запуск Remote Assistance, ping, tracert, C$, Event Viewer, Computer Management,
MSTSC, WinRS cmd и gpupdate. Действия запускаются от текущей Windows-сессии.

Для первого просмотра загружается обезличенный samples/clients.example.csv.
Тёмная тема, проверка всех ПК, определение домена, подготовка SMB-сессии, сообщения
с подтверждением и управление локальными администраторами пока остаются только
в WPF-версии. Настройки и путь к CSV в прототипе не сохраняются.

Сборка с LLVM-MinGW или MinGW-w64:

```powershell
.\src\QuickRemoteToolkit.Win32\build.ps1 -Compiler 'C:\path\to\llvm-mingw\bin\clang++.exe'
```

Готовый EXE находится в win32-publish/ и не требует установки .NET SDK или .NET
Desktop Runtime. Целевая система — Windows 10/11. Дополнительно есть CMake-проект
для MSVC и MinGW. Для запуска на другой машине достаточно EXE; пример CSV можно
выбрать вручную через «Выбрать CSV…».

Компилятор нужен только для сборки. WinRS требует WinRM; административная шара
и управление ПК требуют соответствующих прав и сетевого доступа.
