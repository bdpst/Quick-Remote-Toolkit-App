# Дизайн Quick Remote Toolkit

Актуальный интерфейс — принятая пользователем Rust-версия (2026-11-17), исходники
src/QuickRemoteToolkit.Rust/src/ui.rs и design.rs. Старое исследование WPF сохранено
в истории Git; его пиксельное воспроизведение не является текущим требованием.

- Окно 1500×920 логических единиц, минимум 1200×760; собственная шапка32 с версией,
  стандартными действиями свернуть/развернуть/закрыть и перетаскиванием.
- Верхняя панель: монитор с шестерёнкой42×42, название, поиск и бейдж Ctrl+F,
  выбор/обновление CSV, переключатель темы. Поиск и бейдж выравниваются по центру,
  текст не перекрывает бейдж. Маленькая и большая иконки используют один рисунок/акцент.
- Основная область: таблица клиентов, правая панель действий320, журнал снизу.
  Разделитель изменяет высоту журнала при перетаскивании; таблицы имеют собственную
  прокрутку. Сворачиваемые секции не блокируют доступ к другим действиям.
- Шрифты Segoe UI и Segoe MDL2 Assets загружаются из Windows с fallback;
  основной текст12, заголовок22. Не распространять системные файлы шрифтов.
- Цвета обеих тем определяет Palette::new в design.rs; docs/design-tokens.json
  является компактной картой. Рамки1, скругления карточек12. Не задавать независимо
  цвета, нарушающие контраст текста/hover/disabled/selection.
- Диалоги сообщений и администраторов используют ту же тему. Enter/Ctrl+Enter
  проверяют ввод; ошибки видимы. Долгие действия выполняются в фоне, повторный запуск
  защищён; результат и тайм-аут отражаются в журнале.
- Сохранить сортировку, перенос/ширину колонок, выделение/копирование, клавиатурный
  поиск и видимые состояния избранного. Tooltip не заменяет доступную подпись.

Проверка затронутого UI: обе темы, минимальное окно, длинный/пустой список,
невалидный ввод, поиск/Ctrl+F, splitter и затронутые диалоги. QA-host даёт реальные
framebuffer-снимки; физические DPI/мультимониторные проверки описываются отдельно.
Текущие снимки главного окна: images/main-light.png и images/main-dark.png.
