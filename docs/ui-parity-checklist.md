# Проверка Rust UI

Историческая попиксельная сверка WPF завершена решением пользователя принять Rust.
Этот список используется для затронутых UI-сценариев, а не заявляет выполненные тесты.

- Главное/минимальное окно, светлая и тёмная тема.
- Поиск, Ctrl+F внутри поля, пустые/длинные данные.
- Избранное, сортировка, ширина/порядок колонок, выделение и копирование.
- Перетаскивание разделителя журнала, прокрутка и сворачиваемые секции.
- Диалоги: Enter/Ctrl+Enter, невалидный ввод, сообщения об ошибках.
- Совпадающий монитор с шестерёнкой в заголовке/toolbar; версия в заголовке.
- Фоновые события и запрет повторного запуска без зависания UI.
- DPI/несколько мониторов и физический ввод проверять отдельно, результаты не предполагать.
