# Чеклист соответствия UI

Эталон, точные значения и источники — [гайд](design-guidelines.md); токены — [JSON](design-tokens.json). SHA main: `91689516c96d52877bba3480bf498b7d807ead64`.

Это **не выполненные тесты Rust** и не подтверждение внешнего вида WPF. Все пункты пока не отмечены: захват эталонного окна не удался. Для каждого пункта вести два результата: light и dark, указывать ОС, SHA сравниваемых сборок, размер окна в DIP, размер кадра в px, DPI/масштаб, сценарий и отклонение. Отмечать пункт только после обеих тем. Для реального снимка сохранять также эти метаданные; не подменять снимки реконструкцией.

Данные только обезличенные. Для набора сценариев подготовить UTF-8 и 1251 с одинаковыми кириллическими полями, длинными значениями, повтором Computer с другим регистром, строкой с Computer «-» и IP, строкой без обоих. Удалённые сценарии — только разрешённая тестовая цель; без неё оставлять «не проверено» с причиной. Не нажимать Remote Assistance двойным кликом на рабочем ПК ради кадра.
