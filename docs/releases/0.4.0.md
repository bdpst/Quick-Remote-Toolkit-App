# Quick Remote Toolkit 0.4.0

Стабильная версия на Rust — единственная поддерживаемая реализация. Предыдущий релиз: v0.3.0.

- Самостоятельная Windows x64 поставка без .NET Desktop Runtime; прежние WPF и C++ исходники удалены из текущего дерева, сохранены в Git history.
- Принятый Rust-интерфейс: обе темы, таблицы и избранное, поиск/Ctrl+F, контекстные меню и диалоги удалённой поддержки.
- Исправлены изменение высоты журнала перетаскиванием, выравнивание поиска и бейдж Ctrl+F. Единая читаемая иконка монитора с шестерёнкой в заголовке, toolbar и EXE.
- Сохранены CSV UTF-8/Windows-1251, путь `%AppData%\QuickRemoteToolkitApp\settings.json`, избранное и неизвестные JSON-поля. Перед первой записью существующего файла создаётся settings.before-rust.json; повреждённый JSON защищён от перезаписи defaults.
- Windows version metadata, заголовок и BUILD-INFO.json показывают 0.4.0. SHA256SUMS проверяет ZIP; BUILD-INFO.json указывает точный коммит и SHA-256 EXE.

## Запуск и переход

Распакуйте QuickRemoteToolkit.Rust-win-x64.zip, запустите QuickRemoteToolkitRust.exe.
Нужны Windows 10/11 x64 и OpenGL 3.3 видеодрайвер; средства разработки не требуются.
Старые CSV/settings используются без конвертации. Не запускайте разные версии одновременно для изменения настроек.
Журнал живёт в памяти до закрытия; сохраните через экспорт TXT/CSV.

## Требования и ограничения

Удалённые операции используют текущую Windows-сессию без паролей в приложении.
Нужны соответствующие права и службы SMB/WinRM/WTS/RDP; запуск инструмента не подтверждает завершение удалённой операции.
Реальные административные действия на тестовых ПК и отдельная чистая desktop Windows без SDK не проверены при подготовке релиза. GUI-host проверки не подтверждают все физические DPI/мультимониторные сценарии. CSV-поля с разделителем/переводами строк не поддерживаются импортом.
