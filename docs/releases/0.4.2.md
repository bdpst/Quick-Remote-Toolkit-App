# Quick Remote Toolkit 0.4.2

- Размер главного окна можно менять перетаскиванием за любой край или угол. Минимальный размер составляет 1200 × 760 логических пикселей.
- Приложение отключает ожидание вертикальной синхронизации OpenGL, чтобы быстрее показывать новые кадры при изменении размера окна.

Распакуйте архив Windows x64 и запустите `QuickRemoteToolkitRust.exe`.
