# Quick Remote Toolkit 0.4.1

- Полное имя выбранного ПК и IP видны рядом с действиями. Команды для конкретного ПК становятся доступны после выбора.
- Основные колонки читаются в минимальном окне. Экспорт под рукой, а полный результат операции можно прочитать над журналом.
- Крестик в поле поиска очищает запрос и возвращает фокус в поле. Фильтр избранных управляется отдельно.
- Высоту журнала можно менять мышью или стрелками, когда разделитель в фокусе. Home возвращает исходную высоту.
- Улучшены контраст кнопок и выбранных строк, видимость клавиатурного фокуса и сообщения об ошибках в обеих темах.

Распакуйте Windows x64 ZIP и запустите QuickRemoteToolkitRust.exe. Существующие CSV,
избранное и настройки AppData работают без конвертации. Семантика удалённых
операций сохраняется. Обе темы и диалоги проверены на тестовых данных при 100%.
