# Модель документов
- Reference: branch, full SHA, дата, способ извлечения, ограничения.
- Rule: область/компонент, значение, единица, source (путь и символ), evidence (source/runtime/visual-pending).
- Token: семантический ключ, original resource, light/dark либо shared, type, unit, source. DIP не равен физическому пикселю.
- ParityScenario: ID, окна, темы, начальное состояние, действие, ожидаемый результат, доказательство.
Связь: сценарий проверяет правило; правило ссылается на токен и фиксированный Reference. Неизвестные системные метрики не получают выдуманных значений.
