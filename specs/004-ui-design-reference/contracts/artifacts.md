# Контракт артефактов
Гайд — русский Markdown, источник каждого существенного правила: фиксированный main, файл и символ. JSON UTF-8: schemaVersion, reference, units, colors (semantic key → resource/light/dark/source), sharedColors, metrics и typography. Все значения цветов точные; единицы явные. Чеклист использует ID матрицы гайда, хранит проверяемые действия и ожидаемые результаты. Непроверенные состояния не отмечаются выполненными. Папка снимков допустима только при реальном захвате.
