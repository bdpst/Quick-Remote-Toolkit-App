# Release contract

Cargo.toml version is 0.4.0; Cargo.lock local package, VERSIONINFO, UI, RUNTIME.txt and BUILD-INFO.json agree. Tag 0.4.0 (also future v* tags supported) must match Cargo version. Build checks run before publication. The stable Release contains Windows ZIP, SHA256SUMS and BUILD-INFO.json with exact checked source commit. No overwrite of published tags/releases. Package runs without old code or managed runtime. GitHub rules are respected.
