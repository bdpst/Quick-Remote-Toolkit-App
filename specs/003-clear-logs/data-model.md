# Data Model

Существующая LogEntry: Time (DateTime), Computer, Action, Result (строки), TimeText для отображения.
Новые поля и постоянное хранилище не добавляются.
Состояния коллекции: N записей → Clear → 0; следующий AddLog → 1 запись.
Ограничение: очищается весь текущий набор; файлы экспорта и клиенты не изменяются.
