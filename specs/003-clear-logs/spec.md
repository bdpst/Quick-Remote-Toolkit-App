# Feature Specification: Очистка журнала

## User Scenarios & Testing *(mandatory)*

### User Story 1 - Начать журнал заново (Priority: P1)

Оператор очищает накопленные записи, чтобы видеть результаты следующих действий.
**Why this priority**: основной и единственный сценарий функции.
**Independent Test**: заполнить журнал, очистить, выполнить следующее действие.

**Acceptance Scenarios**:
1. **Given** есть записи, **When** нажата «Очистить журнал», **Then** все текущие записи исчезают без диалога и без записи об очистке.
2. **Given** журнал пуст, **When** выполнена очистка, **Then** журнал остаётся пустым без ошибки.
3. **Given** журнал очищен, **When** появляется новый результат действия, **Then** он отображается и доступен для экспорта, старые записи не возвращаются.
4. **Given** журнал экспортирован, **When** выполнена очистка, **Then** сохранённый файл не изменяется.

### Edge Cases

- Очистка при выполняющейся операции не отменяет её; результаты, поступившие после очистки, отображаются.
- Выделение и сортировка журнала не ограничивают очистку: удаляются все записи.
- Пустой журнал и повторная очистка безопасны.

## Requirements *(mandatory)*

### Functional Requirements

- **FR-001**: В заголовке журнала доступна кнопка «Очистить журнал», доступная также с клавиатуры.
- **FR-002**: Очистка удаляет все текущие записи без подтверждения и не добавляет служебную запись.
- **FR-003**: Последующие результаты отображаются обычным образом; операции и список клиентов не изменяются.
- **FR-004**: Экспорт после очистки не содержит удалённых записей; ранее сохранённые файлы сохраняются.
- **FR-005**: Кнопка читаема в светлой и тёмной темах, использует общий стиль приложения.

### Key Entities

- Запись журнала: время, компьютер, действие, результат; очистка удаляет текущий набор целиком.

## Success Criteria *(mandatory)*

### Measurable Outcomes

- **SC-001**: Одно нажатие оставляет ноль текущих записей при отсутствии новых событий.
- **SC-002**: Ни одна удалённая запись не попадает в следующий экспорт.
- **SC-003**: Первое последующее событие отображается без перезапуска приложения.

## Assumptions

- Область: основная WPF-версия; отдельные прототипы не затрагиваются.
- Очистка относится к журналу текущей сессии, без удаления файлов и без отмены операций.
- Подтверждение и отмена очистки не требуются для этой локальной функции.
