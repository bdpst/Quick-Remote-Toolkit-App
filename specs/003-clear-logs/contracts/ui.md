# UI contract

В заголовке «Журнал» справа доступна обычная WPF Button «Очистить журнал».
Click вызывает ClearLogs_Click, который очищает _logs целиком без подтверждения и без AddLog.
Кнопка работает с мышью, Tab + Space/Enter, в обеих темах, включая пустой журнал.
Новые события продолжают поступать. Экспорт получает только текущие записи.
