# Quickstart validation

1. Выполнить dotnet build .\QuickRemoteToolkit.App.sln -c Release --no-restore.
2. Запустить WPF-приложение; очистить начальный журнал. Ожидается 0 строк.
3. Повторить очистку пустого журнала, включая Tab + Space: ошибок нет.
4. Создать новое событие обычным действием; видна только новая запись.
5. Экспортировать TXT/CSV: удалённых записей нет; ранее сохранённые файлы не изменены.
6. Проверить светлую и тёмную темы: заголовок и кнопка читаемы, таблица доступна.
7. При поступлении результата продолжающейся операции после очистки новая запись отображается.
8. Выполнить dotnet publish .\src\QuickRemoteToolkit.App\QuickRemoteToolkit.App.csproj -c Release --no-restore -o .\publish.

Фактические результаты проверок фиксируются в validation.md.
