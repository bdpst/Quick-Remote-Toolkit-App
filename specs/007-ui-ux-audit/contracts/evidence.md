# Evidence contract

Все находки содержат поля Finding из ../data-model.md. Снимок подтверждает вид, runtime ввод подтверждает взаимодействие, исходник подтверждает конкретную ветвь кода. Ни один из них отдельно не доказывает успешную удалённую операцию.
Состояния busy/reordered/search/long/empty в QA задаются через qa_scene. Ошибки Enter/Ctrl+Enter инжектируются QA-host. Физический DPI не считается проверенным по размеру framebuffer.
Гайд описывает принятый baseline; предложенные изменения и критерии вынесены в ../audit.md.
