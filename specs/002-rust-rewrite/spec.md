# Feature Specification: Полный перенос Quick Remote Toolkit

**Feature Branch**: `codex/rust-rewrite`
**Created**: 2026-11-06
**Status**: Ready for planning
**Input**: Полностью переписать приложение на Rust вместе с интерфейсом через GitHub Spec Kit.

## User Scenarios & Testing *(mandatory)*

### User Story 1 - Список клиентов (Priority: P1)
Оператор открывает существующий CSV, ищет компьютер и отмечает избранное.
**Why this priority**: Все операции начинаются с выбора правильной цели.
**Independent Test**: Обезличенные CSV UTF-8 и Windows-1251 дают одинаковые строки.
**Acceptance Scenarios**:
1. **Given** CSV, **When** файл выбран, **Then** видны номер, ПК, IP и сотрудник.
2. **Given** избранный ПК, **When** приложение перезапущено, **Then** отметка сохраняется.

### User Story 2 - Удалённая поддержка (Priority: P1)
Оператор запускает инструменты для выбранного ПК и проверяет доступность всех ПК.
**Why this priority**: Основная задача утилиты.
**Independent Test**: Сравнить каждую команду с эквивалентом вручную на разрешённой цели.
**Acceptance Scenarios**:
1. **Given** выбранный ПК, **When** нажата команда, **Then** запускается соответствующий инструмент с этой целью.
2. **Given** недоступный ПК, **When** проверка завершается, **Then** журнал показывает ошибку, интерфейс остаётся доступным.

### User Story 3 - Администрирование и сообщения (Priority: P2)
Оператор отправляет сообщение с ожиданием ответа и меняет членство локальных администраторов.
**Why this priority**: Сохранение полного набора функций существующей версии.
**Independent Test**: На разрешённом ПК проверить ОК, Отмена, тайм-аут и отказ доступа; проверить добавление/удаление тестовой учётной записи.
**Acceptance Scenarios**:
1. **Given** несколько сеансов, **When** отправлено сообщение, **Then** каждый получает сообщение параллельно и имеет отдельный результат.
2. **Given** изменение группы, **When** время ожидания истекло, **Then** результат обозначен как неизвестный и повтор запрещён до завершения операции.

### User Story 4 - Оформление и журнал (Priority: P2)
Оператор выбирает тему и экспортирует журнал.
**Why this priority**: Удобство ежедневного использования.
**Independent Test**: Обе темы читаемы, экспорт TXT/CSV открывается с кириллицей.
**Acceptance Scenarios**:
1. **Given** тёмная тема, **When** приложение перезапущено, **Then** тема сохранена.

### Edge Cases
Повреждённый CSV, пустой список, повторяющиеся имена ПК, отсутствующие настройки, отказ записи, недоступная сеть, некорректная цель, закрытие во время фоновой операции, длинные тексты и масштабирование Windows.

## Requirements *(mandatory)*
### Functional Requirements
- **FR-001**: Читать `number;computer;ip;person` в UTF-8 и Windows-1251; поиск, копирование, избранное и фильтр избранного.
- **FR-002**: Сохранить Remote Assistance, ping, tracert, C$, Event Viewer, Computer Management, MSTSC, WinRS cmd, gpupdate и подготовку SMB.
- **FR-003**: Ограничивать параллельные проверки настройкой; показывать доступность и домен/рабочую группу.
- **FR-004**: Отправлять сообщения до 2000 символов, ожидание 1–3600 секунд, различать ответы по сеансам; текст не журналировать.
- **FR-005**: Менять членство администраторов по SID встроенной группы; тайм-аут 60 секунд означает неизвестный результат.
- **FR-006**: Выполнять операции от текущей Windows-сессии без хранения паролей; безопасно обрабатывать аргументы.
- **FR-007**: Сохранять настройки в профиле, использовать отдельный файл Rust-версии с импортом WPF при первом запуске.
- **FR-008**: Светлая/тёмная темы, сворачиваемые панели, журнал с временем/целью/действием/результатом, экспорт TXT и CSV.
- **FR-009**: Не блокировать интерфейс длительными операциями; не считать запуск процесса успехом удалённой операции.
### Key Entities
- Client: номер, компьютер, IP, сотрудник, статус, домен, избранное.
- Settings: CSV, тема, избранное, фильтр, лимит проверок, тайм-аут.
- LogEntry: время, цель, действие, результат.

## Success Criteria *(mandatory)*
### Measurable Outcomes
- **SC-001**: Все FR-001–009 имеют отмеченные проверки, без заглушек.
- **SC-002**: Список 1000 обезличенных клиентов остаётся доступен для поиска во время проверки сети.
- **SC-003**: Приложение запускается на Windows 10/11 без .NET Desktop Runtime.
- **SC-004**: Настройки, темы и избранное переживают перезапуск; исходные данные WPF не изменяются.

## Assumptions
Цель Windows x64; визуальная структура сохраняется, пиксельное совпадение не требуется. WPF сохраняется в ветке как эталон. Удалённые проверки выполняются только на разрешённых целях. Выпуск Rust не подменяет существующий WPF workflow до проверки паритета.
