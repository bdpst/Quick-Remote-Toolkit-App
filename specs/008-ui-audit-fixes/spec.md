## User Scenarios & Testing

### US1 — Чтение данных (P1)
Оператор читает главные поля, команды и результат операции. При длинном значении он может выбрать строку и прочитать полное значение. Проверка: обе темы, длинные ПК, сотрудники, IPv6 и запись журнала (AC-05).

### US2 — Выбор цели (P1)
Оператор сверяет выбранный ПК рядом с действиями. Given выделение, сортировка сохраняет цель. Фильтр, скрывший цель, и обновление снимают выбор (AC-01). Пустые состояния поясняют причину и следующий шаг (AC-03).

### US3 — Компактное окно (P1)
При 1500×920 и 1200×760 основные заголовки читаются, остальные колонки доступны прокруткой, экспорт и диалоговые кнопки достижимы (AC-02). Клавиатура позволяет видеть фокус и менять или сбрасывать высоту журнала (AC-06).

### US4 — Состояния (P2)
Акцентные кнопки и выбранные строки остаются читаемыми во всех основных состояниях (AC-04). Ошибка диалога выделена, ввод сохранён (AC-08). Ожидание и неизвестный результат различимы.

## Requirements

| Критерий | Проверяемый результат |
|---|---|
| AC-01 / UX-01 | Видны имя и IP; без цели целевые команды недоступны; сортировка/фильтр/обновление соблюдают правила выбора. |
| AC-02 / UX-02 | При обеих ширинах читаются основные заголовки, есть доступ к остальным колонкам и экспорту. |
| AC-03 / UX-03 | Отдельные подсказки для отсутствующего CSV, пустого списка и фильтра; есть действие восстановления. |
| AC-04 / UX-04 | Контраст текста primary и выбора ≥4,5:1. |
| AC-05 / UX-05 | Полный текст выбранной записи доступен без hover и для клавиатуры. |
| AC-06 / UX-06 | Видимый фокус, клавиши изменения высоты/сброса, обе области сохраняют доступную высоту. |
| AC-07 / UX-07 | Карта токенов отражает изменённые значения, источник указан. |
| AC-08 / UX-08 | Ошибка заметна в обеих темах, ввод сохраняется. |

## Success Criteria

Восемь критериев с результатами проверок. Два размера и две темы с сопоставимыми снимками. Фактический масштаб Windows указан отдельно.

## Assumptions

Контракты настроек, загрузки и удалённых операций сохраняются. Проверки используют обезличенные данные. Гипотезы аудита остаются за рамками изменений.
