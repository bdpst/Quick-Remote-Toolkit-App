# Quickstart
В Windows запустить штатный ui-smoke.ps1 в двух размерах и сравнить с evidence из 007. Использовать отдельный профиль, проверить Ctrl+F, выбор/сортировку/фильтр/обновление, Tab и splitter, оба диалога с ошибкой и отменой. Не запускать удалённые команды. Команды сборки, тестов и упаковки в README.
