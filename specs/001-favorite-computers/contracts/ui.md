# UI contract
Звездочка слева в каждой строке: ☆ обычный, ★ избранный. ToolTip описывает следующее действие; доступное имя включает имя ПК. Button активируется Space/Enter и не запускает Remote Assistance двойным щелчком.
Над таблицей CheckBox «Только избранные». Поиск AND избранное. При снятии отметки строка исчезает сразу в этом режиме. Пустой результат допустим; переключатель остается доступен.
Settings JSON дополнен FavoriteComputers и ShowFavoritesOnly. CSV неизменен. Ошибка записи показывает диалог, отменяет изменение.
