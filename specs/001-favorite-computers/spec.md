# Feature Specification: Избранные компьютеры
**Created**: 2026-11-06
**Status**: Ready
**Input**: Отмечать ПК звездочкой, показывать только избранные, сохранять выбор между запусками.

## User Scenarios & Testing
### User Story 1 - Звездочка (Priority: P1)
Пользователь одним нажатием добавляет и убирает компьютер из избранного.
**Why this priority**: Основа быстрого доступа.
**Independent Test**: Нажать звездочку дважды и увидеть оба состояния.
**Acceptance Scenarios**:
1. Given обычный ПК, When нажата звездочка, Then она заполнена.
2. Given избранный ПК, When нажата звездочка, Then отметка снята, удаленное действие не запускается.

### User Story 2 - Только избранные (Priority: P2)
Пользователь включает фильтр рядом со списком.
**Why this priority**: Сокращает список до нужных ПК.
**Independent Test**: Отметить один из двух ПК и включить фильтр.
**Acceptance Scenarios**:
1. Given включен фильтр, When введен поиск, Then видны только совпавшие избранные.
2. Given включен фильтр, When снята последняя отметка, Then список пуст; выключение фильтра возвращает ПК.

### User Story 3 - Сохранение (Priority: P1)
Пользователь после перезапуска видит прежние отметки и режим фильтра.
**Why this priority**: Исключает повторную настройку.
**Independent Test**: Перезапустить приложение после изменения отметки и фильтра.
**Acceptance Scenarios**:
1. Given сохраненная отметка, When CSV перезагружен или изменен IP, Then отметка сохраняется по имени ПК.
2. Given ошибка сохранения, When пользователь меняет отметку, Then показана ошибка, изменение отменено.

### Edge Cases
- Повторяющиеся имена без учета регистра имеют общую отметку; пробелы по краям игнорируются.
- Пустое имя или дефис: использовать IP как резервный идентификатор; без обоих отметка недоступна.
- Исчезнувшие из CSV ПК остаются в избранном на случай возвращения.
- Старые настройки открываются с пустым избранным и выключенным фильтром.

## Requirements
### Functional Requirements
- **FR-001**: Звездочка доступна мышью и клавиатурой, показывает текущее состояние в обеих темах.
- **FR-002**: Фильтр избранного объединяется с поиском через И и не меняет CSV.
- **FR-003**: Отметки и режим фильтра сохраняются сразу в профиле пользователя.
- **FR-004**: Перезагрузка и смена CSV не удаляют сохраненные отметки.
- **FR-005**: Ошибка записи явно сообщается и не выдается за успешное сохранение.
### Key Entities
- Избранный компьютер: устойчивое имя (либо резервный IP), состояние отметки.
- Предпочтения пользователя: набор избранных и режим отображения.

## Success Criteria
### Measurable Outcomes
- **SC-001**: Добавление и удаление отметки требуют одного нажатия.
- **SC-002**: После перезапуска восстановлены 100% успешно сохраненных отметок.
- **SC-003**: При фильтрации ни один обычный ПК не отображается, включая поиск.

## Assumptions
- Функция относится к основной WPF-версии.
- Избранное общее для CSV текущего пользователя; переименованный ПК считается новым.
- Массовые удаленные действия сохраняют существующую область выполнения.
