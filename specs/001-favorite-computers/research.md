# Research
- Decision: имя ПК Trim + ToUpperInvariant с префиксом computer:, резервный IP с префиксом ip:.
  Rationale: стабильность при смене IP, одинаковое поведение повторяющихся строк.
  Alternatives: номер строки нестабилен, пара имя+IP теряет отметку при DHCP.
- Decision: сохранять существующий AppSettings сразу, файл заменять атомарно.
  Rationale: старые настройки совместимы, ошибка не портит предыдущий файл.
  Alternatives: отдельное хранилище создает лишний механизм.
- Decision: Button со звездами ☆/★ и OneWay-состоянием, отдельный CheckBox фильтра.
  Rationale: обработчик сначала сохраняет, затем обновляет модель; клавиатура работает штатно.
  Alternatives: двусторонний ToggleButton усложняет откат и двойной щелчок таблицы.
Все технические вопросы разрешены по существующему коду; внешних зависимостей нет.
